# 똑같이 나누세요 — 물 똑같이 나누기 (261120)
커다란 물통 하나(2,000ml)를 플레이어가 정한 컵 2~50개에 최대한 똑같이 나눠 따르는 게임. `index.html`을 열면 실행(file:// 가능).

## 흐름
메인(실제 게임 화면 미리보기 + 제목 + 컵 개수 입력 + 시작하기) → 플레이 → 결과(점수 · 컵 N개 · 컵별 수위 · NEW RECORD · 다시 도전 / 이미지 저장). 5단계·해금·등급·콤보는 폐지.

## 규칙
- 컵당 목표 = 2000 / 컵 수, 컵 용량 = 4000/3 ml 고정(컵 개수와 무관, 같은 ml 은 같은 수위, 2개 75% · 50개 3%), 유속 = 500ml/s 고정(컵 개수와 무관) (판이 시작될 때 확정, `WS.calcSettings`).
- 물줄기가 컵 입구와 겹친 비율만 컵에 들어가고 나머지는 흘린 물. 컵 + 흘림 + 물통 잔량 = 2000 항상 보존. 물통이 비면 종료.
- 점수(`js/scoring.js`): RMSE / 목표 → 100 − 상대오차×100. 흘린 물 별도 페널티 없음.
- 기록: 컵 개수별 최고 점수 (localStorage `waterSplit.v2.best`, 마지막 컵 개수 `waterSplit.v2.cups`). 이전 5단계 키와 분리.

## 구조 (전역 `WS`)
`config`(수치·물통 에셋 경로) → `scoring` → `records` → `cups`(기본 유리컵 에셋·수위 변환) → `cupimg`(결과 이미지용 컵, `node tools/build_cupimg.js`) → `rendering`(레이아웃·렌더) → `game`(로직·화면) → `result` → `menu`(컵 개수 입력) → `input` → `main`
- 컵 개수별 레이아웃은 `js/layout.js` 한 곳(2~19개 5열·최대 420px, 20~39개 8열·620px, 40~69개 10열·760px·컵 0.9배, 50개까지 10열·0.9배). 메인 미리보기·플레이·결과·PNG 모두 같은 함수를 쓴다. 화면이 좁으면 열 수는 유지한 채 컵·간격이 비율대로 줄고, 높이는 행 수만큼 세로 스크롤(가로 스크롤·카메라 없음). 마지막 줄은 가운데 정렬.
- 물통: ←→ 자유 이동, ↑↓ 한 줄 이동(이동 중 물 공급 중지, 가로 위치 유지, 페이지가 해당 줄로 스크롤). 판정은 현재 줄 컵만 검사.
- 메인 사진은 컵 개수 입력과 무관하게 항상 같은 그림(컵 5개, 높이 200px 고정, 물통·조작 없음, 컵마다 물높이 제각각).
- 물통은 항상 왼쪽으로 기울고(주둥이 = 물통 왼쪽), 스냅·반전 없음. 이동 키를 계속 누르면 점점 빨라짐(`moveRampMax`).
- 물통 에셋 교체: `js/config.js` 의 `bottle` (경로·크기·crop·주둥이 오프셋·내부 물 영역).
- PC: ← → 이동, ↑ ↓ 줄 이동, SPACE 홀드 따르기, R 다시 따르기 / 모바일: 하단 [↑][↓][←][→][물 따르기] (멀티터치)

## QA
`node tools/qa_game.js` — 입력 검증, 컵 수별(5~50)의 열·행·가로폭·컵 크기·간격 표, 메인 미리보기, 모바일 열 수 유지, 자유 이동, 줄 이동, 왼쪽 기울기, 주둥이=물줄기=판정, 총량 보존, 종료, 점수, 기록, 결과 이미지(컵 50개), 모바일 멀티터치. 스크린샷은 `screenshot/`.
